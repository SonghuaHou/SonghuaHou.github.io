# Songhua Hou — Personal Website

Hi, I'm Songhua Hou (侯松华), a second-year Digital Media and Culture student at King's College London.

This is my personal portfolio at **https://songhuahou.github.io**, collecting my work across three areas:

- **Writing 写作** — magazines, papers and reports, including a zine on wearable tracking and the quantified self
- **Design 设计** — classroom keynotes, drama-club training decks and posters
- **Visual Media 视觉媒体** — daily photography, short films and interviews

Built with [Astro](https://astro.build) as a fast static site, deployed via GitHub Pages. Reach me at [songhua_hou@outlook.com](mailto:songhua_hou@outlook.com).
